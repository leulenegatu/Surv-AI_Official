# Roadmap

Implemented: local accounts/onboarding, point-in-time camera observations, local person detection, Smart Surv, Camera Areas/rotation/orientation, persistent owned history, optional Windows/browser context, independent context sessions, Analytics Explorer, local evidence-based Ask, usage estimates, PDF archives, retention/export/deletion and optional hidden Windows startup. See [the feature table](../README.md#what-is-implemented).

Future directions, not completed features:

- Broader physical multi-camera, sleep/resume, prolonged-use and installation acceptance.
- Independent accessibility and security review, documented restore/upgrade procedures.
- Longitudinal insights that preserve evidence limits and uncertainty.
- User-defined goals and richer contextual recall.
- Optional wearable/device integrations with separate explicit consent.
- Evidence-aware professional review reports, without diagnosis or unsupported duration claims.

Cloud synchronization, Google sign-in, outbound recovery email, RTSP ingestion and wearable integration are not part of the current release. No delivery dates are promised.
